Dokumentasi Sistem Manajemen Sekolah

Panduan lengkap penggunaan fitur-fitur aplikasi untuk Admin, Tata Usaha, dan Guru.

Selamat Datang di Sistem Baru

Aplikasi yang dulunya hanya berfokus pada jadwal, kini telah diekspansi menjadi Sistem Manajemen Sekolah terpadu yang mencakup Kesiswaan, Administrasi Surat, API Notifikasi, dan keamanan Audit Log.

100% Terintegrasi

Seluruh modul mulai dari Jadwal, Data Siswa, Surat-menyurat, hingga Keamanan saling terhubung dalam 1 database (PostgreSQL).

Cepat & Responsif

Didesain dengan React dan navigasi tanpa loading antar halaman. Manajemen data masif dilakukan secara instan.

Informasi Umum

Profil Sekolah & Tahun Ajaran

Menu ini digunakan untuk mendefinisikan identitas sekolah dan mengontrol periode data yang sedang aktif.

  • ✔ Identitas Sekolah: Nama, NPSN, Alamat, Logo, dan Tanda Tangan Kepala Sekolah yang akan digunakan sebagai *Kop Surat* otomatis pada semua laporan dan E-Surat.
  • ✔ Tahun Ajaran: Anda dapat membuat Tahun Ajaran baru (Misal: 2026/2027) dan menentukan Semester (Ganjil/Genap). Penting: Hanya ada 1 (satu) Tahun Ajaran yang dapat di-set sebagai "Aktif". Semua data transaksi akan otomatis merujuk ke periode aktif ini.

E-Surat & Template (Surat Panggilan)

Digunakan oleh Tata Usaha atau BP/BK untuk membuat surat administratif secara instan.

  • ✔ Pencarian Siswa Otomatis: Cukup cari NIS atau nama siswa, sistem akan mengisi data diri dan orang tua mereka ke dalam template surat.
  • ✔ Jenis Surat: Tersedia Surat Panggilan (SP1, SP2, SP3), Surat Pemberitahuan, dan Surat Mutasi.
  • ✔ Kustomisasi Pesan: Tambahkan detail pelanggaran/keperluan secara langsung sebelum dicetak. Hasil cetak akan menyesuaikan ukuran kertas A4 secara otomatis.

Kesiswaan & Data Master

Proses Kenaikan Kelas & Kelulusan

Menu kritis yang dijalankan di akhir Tahun Ajaran Genap. Proses ini memindahkan seluruh data siswa tingkat X ke XI, XI ke XII, dan XII menjadi Alumni/Lulus secara bersamaan.

  1. Buka menu Kenaikan Kelas.
  2. Pilih Tahun Ajaran Baru (tujuan perpindahan).
  3. Review data siswa. Jika ada siswa yang tinggal kelas, klik tombol "Tidak Naik" di baris siswa tersebut sebagai pengecualian.
  4. Klik tombol Proses Kenaikan Kelas. Sistem akan mengubah kelas mereka secara otomatis di seluruh database dan membuat log riwayat proses.

Kartu Pelajar Generator

Generator pembuatan ID Card Siswa secara massal tanpa memerlukan aplikasi eksternal (seperti Corel/Photoshop).

Desain Kustom

  • Ubah warna dominan kartu.
  • Otomatisasi pas foto dari database.
  • Sistem *Auto-Generate* QR Code dari NIS siswa yang terhubung ke mesin tap-absen.

Pencetakan

  • Dapat mencetak langsung 1 kelas penuh (disusun rapi pada kertas A4).
  • Dapat mencari dan mencetak hanya 1 siswa jika kartu hilang.

Konfigurasi Sistem Khusus Admin

⚠️ Akses ke modul-modul ini sangat dibatasi dan dianjurkan hanya dilakukan oleh IT Support Sekolah atau Superadmin.

Manajemen API Key

Gudang integrasi pihak ketiga. Anda menaruh kode/kredensial untuk WhatsApp dan Google Drive di sini.

  • Fonnte (WhatsApp): Masukkan TOKEN akun fonnte Anda agar fitur blast WA terbuka.
  • Google Drive: Masukkan file/teks JSON Service Account Google Cloud Anda agar backup otomatis dapat ditulis ke Drive.

Integrasi WhatsApp (Auto/Blast)

Memanfaatkan API yang sudah di-set di atas untuk mengirim pesan ke nomor WA orang tua/siswa.

  • Mendukung pesan massal (*Blast*) kepada spesifik kelas (Misal: Pengumuman libur).
  • Mendukung parameter dinamis (*Mail Merge*) seperti {NAMA_SISWA}, {KELAS}.
  • Terdapat Log Pengiriman untuk mengetahui pesan mana yang Gagal (*Failed*) karena nomor tidak valid.

Google Drive Backup (Terenkripsi)

Sistem menjadwalkan pencadangan (*dump*) seluruh database PostgreSQL setiap hari pukul 02:00 pagi (WIB) secara *background* jika API Key valid.

Anda juga dapat menekan tombol Backup Manual untuk langsung membuat *snapshot* saat itu juga sebelum melakukan perubahan berisiko (seperti Kenaikan Kelas).

Audit Log Keamanan

Sebuah "CCTV" aktivitas dalam aplikasi. Setiap kali *user* (terutama yang bukan admin utama) menambah, mengubah, atau menghapus data, sistem merekam:

  • Siapa pelakunya (Username).
  • Waktu kejadian (Timestamp).
  • Tindakan apa yang dilakukan (Misal: Menghapus siswa bernama Budi).
  • Dari IP Address mana mereka mengakses.

Troubleshooting (Masalah Umum)

Halaman 'Blank Screen' setelah login?

Ini terjadi jika *cache* browser Anda masih memegang versi lama, atau token di `sessionStorage` tidak sinkron dengan server. Solusinya:
1. Tekan CTRL + F5 (Hard Refresh).
2. Hapus *Cookies* dan *Local Storage*.
3. Relogin.

WhatsApp gagal terkirim (Status: Error)?

Kemungkinan penyebab:
- Token Fonnte kedaluwarsa atau salah input di menu Manajemen API Key.
- Nomor tujuan tidak memiliki awalan yang benar (Sistem secara otomatis mencoba mengonversi '08' menjadi '628', namun nomor yang asal-asalan tetap ditolak provider).
- Kuota paket Fonnte (kredit) Anda sudah habis.

Data yang dihapus muncul lagi (Bug Sinkronisasi)?

Aplikasi versi terbaru telah memastikan hanya menggunakan 1 sumber kebenaran data yaitu PostgreSQL Server (kami menghapus penyimpanan lokal / JSON). Jika ini terjadi, pastikan Server Backend Node.js Anda (`auth-server.mjs`) tetap hidup dan tidak *error*. Cek terminal Laragon/NodeJS Anda jika koneksi *database* terputus.
